# Salad Manager

**Salad Manager** — це Java-застосунок для керування салатами, інгредієнтами та, за потреби, замовленнями/меню.  
Проєкт створений для зручної роботи з даними про страви та їх склад.

## Можливості

- Додавання, редагування та видалення салатів
- Управління інгредієнтами
- Перегляд складу страв
- Зручний інтерфейс для роботи з даними
- Можливість розширення функціоналу під нові потреби

## Технології

- **Java** — основна мова проєкту
- **CSS** — стилізація інтерфейсу
